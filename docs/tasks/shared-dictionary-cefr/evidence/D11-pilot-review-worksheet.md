## Review procedure

Assign a Dutch-as-a-second-language reviewer before any provider sample. For each
meaning, verify the gloss/example/grammar, then record an acceptable A1–C2 level
set or abstention, ambiguity, reason/evidence reference and permission reference.
Do this without seeing provider predictions. A disputed meaning needs independent
adjudication; preserve both judgments. A second reviewer should check all sense
pairs, ambiguous/conflicting and specialized cases, plus a stratified 25% of the
remainder. Reviewers can replace a draft; replacement requires new input hashes
and a new approved sample digest. No reviewer identity is invented.

but not each slice in each split; it cannot establish operational qualification.
Rare/missing tags here mean missing reviewed CEFR evidence in this proposal,
not a measured corpus-frequency claim.

The [Dutch CEFR descriptors published by Taalunie](https://taalunie.org/feeds/download/gemeenschappelijk-europees-referentiekader-9-5dca8.pdf/CEFR_vertaling/original)
describe learners' vocabulary range and control. They do not assign a canonical
band to every Dutch sense. This is why a word's personal learning age, corpus
frequency or lesson occurrence cannot be treated as a universal gold label.

## Quantitative gap

The frozen 24-input pilot has four empty required slice/split cells and used an
assistant-provisional reference. The separate 27-input pool covers all 22 cells,
but has only one to four candidates per cell and no independently adjudicated
meaning-level expectations. Both are useful diagnostics, neither can estimate
operational accuracy. Even with **zero** errors among 27 independent held-out
items, the exact one-sided 95% upper bound for the error rate would be 10.5%
(`1 - 0.05^(1/27)`); with four it would be 52.7%. This calculation assumes
independent representative sampling, which these deliberately selected inputs
do not provide. It demonstrates only how little a small sample can establish.

A prospective design should set a meaningful minimum in each of the eleven
required slices in both splits, keep all related meanings in one split, and
report per-cell denominators plus interval estimates. Ten independent items
per cell would mean up to 220 single-slice items and still provide only a
coarse per-cell smoke check. For a pooled zero-error held-out result, 59
independent accepted items are needed merely to bound the error rate below 5%
at one-sided 95% confidence; nonzero errors require more. These are planning
illustrations, **not** accepted production thresholds or a claim that the
available sources can label 220 exact senses. Confidence calibration,
coverage, abstention and severe errors must be reported separately.

## Concrete next path to the original exit

1. Establish a rights-compatible, independently adjudicated exact-sense
   reference. Reviewers must be identified and blind to the method under test.
   At minimum, the answer key must distinguish acceptable level sets,
   expected abstentions and genuinely disputed/unsupported senses. If no
   such reference can be obtained, retain `qualified: false` and do not claim
   the original gate complete.
2. Expand a distinct-family calibration/held-out pool before scoring and
   freeze input hashes, source citations, licenses, splits and review records.
   Use NT2Lex only as corroborating frequency evidence where rights permit;
   use contrastive cases as a separate safety suite.
3. Specify minimum denominators, coverage, exact/within-one, accepted
   accuracy, severe-error and abstention thresholds **before** provider
   responses. Run parser, family-isolation and fake-provider checks locally.
4. Present the exact new input manifest, destination, request count and cost
   estimate for separate authorization. The two remaining Gemini attempts
   apply to the original 24 only. A new provider sample and server approval
   are independent gates; no current authorization covers them.

As of this audit, the missing reference is the first irreducible dependency.
Additional assistant labels, independent model votes or NT2Lex lookup can
triangulate uncertainty, but cannot be represented as external human gold.
